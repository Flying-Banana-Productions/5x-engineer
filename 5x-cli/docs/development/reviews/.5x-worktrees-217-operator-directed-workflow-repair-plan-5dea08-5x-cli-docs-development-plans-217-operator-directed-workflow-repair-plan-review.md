- **Repair authority is explicit and proactive.** The run form works during drift and without an existing gate; native chat authorization is recorded once, and unchanged repair intent survives preview refresh.

- **Approval provenance is separated from reviewer history.** A finalization anchor reconciles final committed bytes and ledger without rewriting the original snapshot or relaxing exact-hash assessment of semantic amendments.
- **Tests measure operator experience as well as record correctness.** Same-run recovery, invocation counts, restart/replay, historical inconsistent state, and effective installed/override-rendered assets are required outcomes.
